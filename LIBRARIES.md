## KiCAD Libraries
We have prepared a compiled library for RDC which can be downloaded (here)[].

The library should consist of:
1. Footprint Library    :Footprint_Lib.pretty  
2. DRC Template file    :DRC_template.zip  
3. Symbol Library       :Symbol_Lib.kicad_sym
4. TFT image            :TFT_LCD.DXF

[Here](https://docs.google.com/presentation/d/1QGDdVWUe8z_BoH64QIoPZkyOlaU00QqF/edit?slide=id.p1#slide=id.p1) is the guide on how to import the Libraries into KiCAD
